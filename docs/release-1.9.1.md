# 1.9.1 — compact backend landing

The backend landing now uses compact, rounded pill links for Editor, SoMe Generator and Stock Control. Tool descriptions, arrow glyphs and the introductory subtitle are removed. The title and spacing are smaller, and pills wrap naturally on narrow screens with a minimum 48px touch target and visible keyboard focus. The existing top navigation and editable background are retained.

Verification: npm run check (TypeScript, complete automated suite and production build). No real-device visual verification or deployment is claimed.
