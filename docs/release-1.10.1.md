# 1.10.1 — menu-style landing page

The admin landing page now shows the same five destinations as the backend menu, without descriptions: Tools, Editor, SoMe Generator, Stock Control and View site. The landing page shares the menu surface colour, padding, display typography, row spacing, responsive sizes and divider colour. Pills and the separate heading are removed. The floating website header remains available.

The landing page follows the website menu background (Brand colors → main blue/green), while tool workspaces retain Brand colors → Backend.
