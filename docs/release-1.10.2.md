# 1.10.2 — simpler admin navigation and spacing

All admin screens use a single Back pill in the top right linking to `/admin`, replacing the menu icon. Editor and Stock Control retain the unsaved-change warning on this link and the logo. All local All tools buttons are removed. The landing page no longer contains the Tools self-link.

The admin header now has an opaque palette-matched surface so controls remain readable while forms scroll. Main titles have a calmer scale, section and card headings have distinct roles, and cards, labels and inputs follow consistent spacing. Stock save actions use a compact two-column mobile layout, with tabular numeric values and contained scrolling tables. The social preview takes less vertical space on phones. Public navigation and media are unchanged.

Validation: npm run check. Browser/device visual verification was unavailable. No deployment is included.
